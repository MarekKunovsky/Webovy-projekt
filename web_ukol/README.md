# Dovolená v České republice

## Popis projektu

Tento projekt představuje návrh webových stránek pro dovolenou v ČR.

Web obsahuje:
- hlavní stránku
- kontakt
- blog
- o nás
- galerii
- ceník
- služby
- FAQ
- destinace

---

## Struktura webu

| Stránka | Popis |
|---|---|
| Home | Úvodní stránka |
| O nás | Informace o společnosti |
| Kontakt | Kontaktní formulář |
| Blog | Články |
| Galerie | Fotografie |
| Ceník | Přehled cen |
| Služby | Nabídka služeb |
| FAQ | Časté dotazy |
| Destinace | Nabídka míst |
